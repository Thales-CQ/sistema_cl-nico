# Requisitos

## Versão inicial

### Autenticação

- Login;
- Logout;
- Controle de sessão/autenticação;
- Proteção de rotas.

### Pacientes

- Cadastro;
- Consulta;
- Pesquisa;
- Visualização;
- Edição;
- Inativação.

## Funcionalidades futuras

- Funcionários;
- Especialidades;
- Procedimentos;
- Especialistas;
- Procedimentos realizados por cada especialista;
- Valores específicos por especialista;
- Convênios;
- Agenda;
- Atendimentos;
- Prontuários;
- Adendos;
- Relatórios;
- PDF;
- Auditoria;
- Financeiro;
- Backup;
- Instalador.

### Agenda frontend-only futura

- Calendário navegável iniciado no dia atual, com navegação para datas passadas
  e futuras;
- Visualizações diária e semanal;
- Lista de agendamentos.

Esta etapa futura cobre somente a interface. Fonte dos dados, API e operações
de agendamento permanecem dependências de etapas posteriores.
