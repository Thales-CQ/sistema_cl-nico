# Sistema Clínico

Sistema web para gerenciamento de informações clínicas.

## Objetivo inicial

A primeira versão do sistema terá como foco:

- autenticação de usuários;
- cadastro de pacientes;
- consulta e pesquisa de pacientes.

## Tecnologias

### Frontend
- React
- Vite
- JavaScript

### Backend
- Python
- Flask
- API REST

### Banco de dados
- MySQL

### Infraestrutura
- Linux
- Git
- GitHub

## Arquitetura

O frontend será responsável pela interface do usuário.

O backend será responsável por:

- autenticação;
- autorização;
- validação;
- regras de negócio;
- comunicação com o banco;
- segurança da API.

O banco de dados será MySQL.

## Desenvolvimento

O sistema será desenvolvido incrementalmente.

Cada funcionalidade será:

1. planejada;
2. implementada;
3. testada;
4. revisada;
5. versionada no Git.

## Primeira versão

A primeira versão funcional terá:

- Login;
- Dashboard;
- Cadastro de pacientes;
- Consulta de pacientes.

Funcionalidades como especialistas, procedimentos, preços, convênios, agenda, prontuários, relatórios e financeiro serão adicionadas posteriormente.
